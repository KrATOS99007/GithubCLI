This Project uses the following Github API
https://api.github.com/search/repositories?q=created:2024-01-01&sort=stars&order=desc&per_page=20
The aim is to find trending repositories for a provided time interval
Before a certain Date, After a certain date, and in a given Date Range alongwith limit of results which is defaulted to 10

The idea of the project was to learn basic structure of a springboot application, use third party api within backend using HTTP Client(RestServiceTemplate used)
